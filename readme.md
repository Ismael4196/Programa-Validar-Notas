# Validador de notas

Programa sencillo para validar las notas ingresadas. Su función es comprobar que el dato tenga un formato numérico y se encuentre dentro del rango establecido; no indica si el estudiante aprueba o reprueba.

## Uso

1. Ejecuta el programa.
2. Ingresa la nota que deseas validar.
3. Revisa el mensaje que muestra el programa: confirmará si la nota es válida o si debes ingresarla nuevamente.

## Objetivo

Practicar la lectura y validación de datos, evitando valores no numéricos o fuera del rango permitido.
